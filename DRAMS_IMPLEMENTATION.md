# DRAMS native collection

All 52 distinct components listed on [DRAMS](https://drams.framer.website/) are implemented as native HTML/CSS/JavaScript with copyable code. The five remix previews repeat existing entries; number 049 is absent from the public catalog. The [catalog manifest](DRAMS_CATALOG.json) records the complete source-to-library mapping. Original designs are credited to DRAMS by 1042 Studio (@mrblackstudio and @karimeshrimp).

Every mapped ID is registered, compared with its live reference, and checked in rest and operated states. The components preserve distinct physical geometry and interactions, with pointer and keyboard controls, restrained materials, and regular Inter typography. These are independent native interpretations of the source designs. Attribution appears in each details panel and in its copied HTML document.

The library now contains 399 demos, including these 52 DRAMS entries and four additional configurable Framer-inspired data components. All 20 original skeuomorphic demos were separately rebuilt from scratch. The DRAMS filter exposes the complete collection in source-number order.

Verification covers all 399 previews, 560 library checks, and 97 offline code exports, including every DRAMS entry and every rebuilt original hardware demo. Per-component source observations, screenshots and exact interaction checks are recorded in the [complete audit](LIBRARY_AESTHETIC_AUDIT.json). Demos were reviewed at 300×320 and in wider library modals; the library shell was also checked at a 390px mobile viewport.
